# Museum item tracker

Live tracker for the METAcraft SMP Museum Collection Competition: shows every Minecraft 26.3 item
(plus server mod items) a team hasn't submitted yet, updating every 5 seconds from metacraft.se.

Pick your team at the top, or link straight to one with `?team=east`, `?team=west` or `?team=south`.
Filters: categories, difficulty sort, craftable only, items other teams already have, hiding items
for now. Click an item to see its crafting recipe.

It's a single `index.html` with no build step; GitHub Pages serves it as-is.
